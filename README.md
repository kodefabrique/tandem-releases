# Tandem desktop releases

Public installers and Tauri updater manifests for **Tandem**.

Source code and CI live in the private [`kodefabrique/call-service`](https://github.com/kodefabrique/call-service) repo.
Artifacts are published here so `/releases/latest/download/...` works without GitHub auth.

- macOS: `Tandem-macos.dmg`
- Windows: `Tandem-windows.msi`
- Updater: `latest.json`
